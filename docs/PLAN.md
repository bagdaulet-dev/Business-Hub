# CollectWatch — поэтапный план до сдачи

Дедлайн: **12:00, 15 ноября 2026**. Описание продукта, цифры и критерии — в [PROJECT.md](PROJECT.md).
Отмечайте `[x]`, когда этап готов. Роли: **BE** — бэкенд, **FE** — фронтенд, **PITCH** — питч и дек.

## Этап 0. Доступы и каркас (0–2 ч) — блокирует всё

- [ ] **BE** Каркас Next.js (TypeScript, App Router, Tailwind) в этом репозитории, `.env.example`, `.gitignore` с `.env*`.
- [ ] **BE** Деплой на Vercel из репозитория → получить публичный HTTPS-домен.
- [ ] **BE** Роут `/api/ebay/account-deletion` (GET challenge → `{"challengeResponse": sha256(challenge_code + token + endpoint)}`, POST → 200). Env `EBAY_VERIFICATION_TOKEN`, `EBAY_DELETION_ENDPOINT` в Vercel → redeploy.
- [ ] **BE** developer.ebay.com: аккаунт → keyset → Production → Alerts & Notifications: endpoint + token → тест пройден → `EBAY_CLIENT_ID`, `EBAY_CLIENT_SECRET` в env.
- [ ] **BE** curl-проверка: токен приложения + поиск `charizard psa 10` в категории 183454 возвращает лоты.
- [ ] **BE** Claude Console: ключ `ANTHROPIC_API_KEY` в env (только сервер).
- [ ] **BE** Postgres (Neon/Supabase) → `DATABASE_URL`.
- [ ] **BE** Telegram: @BotFather → `TELEGRAM_BOT_TOKEN`.
- [ ] **FE** Макеты экранов: главная (ввод охоты), находки, детали лота, мои охоты, тарифы.
- [ ] **PITCH** Структура дека по PROJECT.md §13, название и слоган, визуальный стиль.

**Готово, когда:** сайт открывается по домену, eBay Production активен, curl возвращает карточки.

## Этап 1. Ядро агента (2–8 ч)

- [ ] **BE** `lib/ebay.ts`: получение и кэширование токена (2 ч), `searchListings(query, categoryId, priceMin, priceMax)`.
- [ ] **BE** `lib/parseRule.ts`: текст охоты → правило JSON (Claude, structured outputs).
- [ ] **BE** `lib/parseListing.ts`: название лота → поля (карта, сет, номер, язык, грейдер, оценка, 1-е издание, лот/набор, red flags). Кэш по `itemId`.
- [ ] **BE** `lib/market.ts`: рыночная цена = медиана похожих лотов (та же карта + оценка), отсечение выбросов (IQR), запись в `price_history`.
- [ ] **BE** `lib/score.ts`: выгода % = (рынок − цена − доставка)/рынок; риск подделки по эвристикам PROJECT.md §11.
- [ ] **BE** Схема БД (`sessions`, `hunts`, `listings`, `finds`, `price_history`) и миграции.
- [ ] **BE** API: `POST /api/hunts` (создать охоту и сразу вернуть первые находки), `GET /api/hunts`, `GET /api/finds?huntId=`, `GET /api/listing/:id`.
- [ ] **FE** Экраны на моковых данных: главная с примерами-кнопками, лента находок с бейджами «−X%» и риском, детали лота.

**Готово, когда:** запрос «Charizard PSA 9 до $500» возвращает реальные лоты с выгодой и риском.
