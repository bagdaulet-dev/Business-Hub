# CollectWatch

Мобильное веб-демо поиска и сравнения товаров с серверным AI-поиском Pokémon. Нужен Node.js 22, установка пакетов для приложения не требуется. Обычный поиск работает без ключа.

```sh
node server.mjs
```

Откройте http://127.0.0.1:4173. Сервер по умолчанию доступен только на этом компьютере. Для AI используйте запуск с `.env`, описанный ниже.

- «Наушники Sony» и «Камера Canon» показывают явно обозначенные демонстрационные цены и ссылку на соответствующий поиск eBay.
- Пример Charizard использует шесть сохранённых наблюдений eBay. Выберите PSA 9 и бюджет $500, чтобы получить пять результатов. У лота за $350 кнопка «Почему?» показывает медиану $460 по пяти аналогам.
- Введите товар вне набора, чтобы проверить ссылку на поиск eBay из пустой выдачи.

Бюджет и сравнение учитывают цену без доставки и налогов. [Происхождение данных по карточкам](data/demo/HANDOFF.txt).

## API объяснений

По умолчанию «Почему?» показывает локальный расчёт. Для подключения своего API укажите путь того же сайта, например `/api/explain`, в метатеге `collectwatch-explain-endpoint` в `index.html`. При раскрытии результата браузер отправляет JSON через POST. В запросе передаются `title`, необязательный `variant`, `price_cents`, `comparable_prices_cents`, `median_cents` (или `null`) и `source` (`sample` или `snapshot`). Ответ: `{"explanation":"Текст объяснения"}`. При сбое API локальный расчёт остаётся на экране. Ключ провайдера хранится на сервере.

## Серверный AI-поиск Pokémon (интеграция aibarC)

Для Kimi нужен сервер Node.js 22, статического `python http.server` недостаточно:

```sh
node --env-file=.env server.mjs
```

Адрес: http://127.0.0.1:4173. Локальный `.env` не публикуется:

```dotenv
LLM_BASE_URL=https://llm.telecom.kz/v1
LLM_MODEL=kimi-k3
LLM_API_KEY=
```

Обычный поиск, примеры Sony/Canon и раскрытие «Почему?» не вызывают модель. Отдельная кнопка «AI-поиск Pokémon · Kimi» отправляет один POST `/api/search` с текстом и добавленными явными фильтрами формы. Kimi извлекает условия, серверный модуль рассчитывает результат на собственном историческом наборе. Понятые условия показаны над выдачей для проверки. Другая карточка даёт пустой результат; ошибки модели не подменяются статическим поиском.

API: JSON `{ "text": "Charizard ex 199/165 English PSA 9 до $450 минимум на 15% дешевле аналогов" }` → `{ rule, results, parserMode, dataMode, warnings }`; каждый результат имеет `listing`, `peers`, `benchmark`, `delta`, `percent`. Это фактический адаптер статического приложения, а не ранее обещанный Next.js-каркас. Ключ и выбор провайдера доступны только серверу. `/api/search.js` содержит Node-обработчик для Vercel; при развёртывании настройте те же env на сервере и публикуйте только клиентские файлы и API-функцию. Production: https://collectwatch.vercel.app — опубликован через Vercel CLI в проект business-cup1/collectwatch. Серверный Kimi-запрос проверен: HTTP200 и ожидаемый результат. Автодеплой из GitHub пока не настроен: Vercel требует связать GitHub Login Connection; текущий деплой выполнен напрямую из рабочей копии.

Минимальный лимит в памяти процесса ограничивает параллельные запросы и частоту. Для публичного сервиса нужны общая квота/защита доступа на стороне хостинга; лимит отдельного serverless-инстанса не является общим лимитом гранта.

Проверки без внешних API:

```sh
node --test tests/engine/*.test.mjs tests/integration/*.test.mjs
```

Текущую доступность объявлений не подтверждаем. Sony/Canon остаются синтетическими примерами и не отправляются в карточный AI-поиск. Уведомления и автоматический мониторинг ещё не подключены.
