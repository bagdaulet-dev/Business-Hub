# CollectWatch

Мобильное веб-демо поиска и сравнения коллекционных карточек на шести сохранённых наблюдениях eBay. Для запуска достаточно статического HTTP-сервера. Ключи и установка пакетов не требуются.

```sh
python3 -m http.server 4173
```

Откройте http://localhost:4173. Для просмотра с телефона в той же Wi-Fi сети откройте адрес компьютера на порту 4173.

- При `Charizard ex 199/165`, `PSA 9` и бюджете `500` появляются пять результатов. Без бюджета видны все шесть.
- У лота за $350 раскройте «Как рассчитано сравнение?» и проверьте медиану $460 по пяти другим объявлениям.
- Выберите `PSA 10` или введите бюджет ниже $350, чтобы проверить пустую выдачу.

Бюджет и сравнение учитывают цену предложения без доставки и налогов. Доступность лотов не проверена. [Происхождение данных и ограничения](data/demo/HANDOFF.txt).
