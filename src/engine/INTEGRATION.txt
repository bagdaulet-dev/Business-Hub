MODULES
src/providers/rule-parser.mjs: parseRule(text, {complete, timeoutMs}) extracts/validates a rule. Strict validation, null unspecified fields, bounded input/output, deadline, safe errors, no silent fallback or retries. Prompt-only semantic correctness is unverified: model can return valid JSON with wrong meaning; display parsed conditions for user review.
src/providers/anthropic.mjs: createAnthropicCompletion({apiKey, model, apiVersion?, fetchImpl?}) returns complete. Server-only use; no automatic env loading. API key and actual model ID must be supplied by server configuration, not browser input. Construction performs no requests. HTTP mocks tested; live model and account access NOT tested. API reference consulted: https://platform.claude.com/docs/en/api/messages/create and /docs/en/api/overview. Default API version is 2023-06-01; choose a compatible available model/version when configuring.
src/engine/evaluate-rule.mjs: evaluateRule(observations, validatedRule, options) selects matching observations and partitions exact identities. Null constraints are unrestricted, not inferred; separate grade/set/finish groups get separate baselines. Unknown identity fields excluded with warning. Uses source-observation schema, not final app schema.
src/engine/pricing.mjs: evaluatePricing(observations, exactIdentity, options) computes leave-one-out comparisons. minComparables default 3 is an internal configurable choice pending contract confirmation. Filter budget/discount after full baseline. Explicit bundle/accessory/replica flags excluded, unknown item_type is not independently authenticated. No risk scoring.
