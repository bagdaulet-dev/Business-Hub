НАША ГОТОВАЯ ЧАСТЬ
- src/providers/telecom.mjs: серверный OpenAI-совместимый адаптер https://llm.telecom.kz/v1, без автоматических повторов. Ключ из серверной конфигурации, не из клиента.
- src/providers/rule-parser.mjs: извлечение условий и строгая проверка девяти полей. Неуказанные поля null; неизвестные/неподдерживаемые ограничения — ошибка. Проверка JSON не доказывает правильность понимания каждого нового запроса.
- src/engine/run-query.mjs: parseRule → evaluateRule; внутренний вход, не отдельный HTTP-контракт. parser_mode=provider не доказывает живую модель, поскольку тесты подставляют mock.
- src/engine/evaluate-rule.mjs: разбивает подходящие записи на точные группы; разные версии не объединяются в одну медиану.
- src/engine/pricing.mjs: обычный код рассчитывает цены. Аналоги выбираются до бюджетного фильтра; текущий лот исключается из своей медианы; минимум3 аналога по умолчанию. Нет риск-скоринга.
- data/demo/charizard-psa9-source-observations.json: исходные наблюдения и происхождение.
- data/demo/VERIFICATION.txt: независимая повторная проверка доступных источников.

ПОДКЛЮЧЕНИЕ ПРИЛОЖЕНИЯ
Фактический POST /api/search принимает только {text}; сервер сам читает fixture и вызывает runQuery. Ответ содержит rule, results[{listing,peers,benchmark,delta,percent}], parserMode, dataMode, warnings. Endpoint api/search.js (Vercel) — ESM через package.json type=module.
Запуск локально: node --env-file=.env server.mjs, по умолчанию127.0.0.1:4173. Статический сервер отдаёт только разрешённые файлы, .env/src/.git недоступны. Vercel build-static.mjs складывает ровно шесть клиентских файлов в public/. Не публиковать корень репозитория статическим python http.server вместе с .env.
Кнопка AI-поиска Pokémon вызывает Kimi явно. Sony/Canon — отдельные синтетические примеры обычного поиска. Нельзя возвращать эти цены как реальные eBay-объявления.
Сервер имеет лимиты размера, времени, частоты и конкурентности на один процесс. Serverless-инстансы не делят счётчик: это не общая квота гранта.

ОГРАНИЧЕНИЯ ДАННЫХ И РАСЧЁТА
Набор исторический и отобран для демонстрации. retrieved_date — дата получения кэшированной страницы, не дата одновременного рыночного снимка. У всех source_capture_time=null и live_verified=false. Две записи, включая WBG350, независимо повторно открыть не удалось; они сохранены как исходные наблюдения, а не текущие предложения.
Доставка получена для разных ZIP. observed_shipping_cents не заменяет shipping_cents. Сравнение item_price явно исключает доставку/налоги; delivered требует известную нормализованную доставку на один ZIP. Неизвестная доставка не равна0.
350USD против медианы остальных460USD →110USD,23.91% только в историческом наборе. Без минимальной разницы запрос до450USD даёт350 и400; с минимум15% — только350. Никакой победитель не зашит в алгоритм. Исчезновение объявления не доказывает продажу. Дешевизна не является fraud score.

ПОСЛЕДНИЙ ОФЛАЙН-АУДИТ
47 локальных тестов прошли. evaluateRule теперь требует полный валидированный объект из9 полей (неприемлемы {} или неизвестные ограничения); отсутствующие условия нужно передавать явно null. Группы не объединяют противоречащие названия карточек, даже при одинаковом номере. Максимальные денежные значения ограничены MAX_CENTS=floor(Number.MAX_SAFE_INTEGER/2), чтобы сохранить точность медианы с половиной цента; цены обычного демо не изменились.
node src/engine/validate-demo.mjs — офлайн-проверка именно текущего шестизаписного fixture; exit1 при ошибке, внешних запросов нет. data/demo/quality-audit.json содержит воспроизводимую сводку:0 структурных ошибок,8 предупреждений. Эта проверка не подтверждает доступность объявлений, истинность исходных утверждений продавца или подлинность.
