# Отложенное появление реальных наблюдений

Файл `watch-scenarios.json` содержит реальные сохранённые объявления. **Постановочная только задержка появления**, а не товары, цены или страны. Это воспроизведение исторических данных, не живой мониторинг eBay. Все записи: `synthetic:false`, `data_mode:historical_observations`, `arrival_mode:staged`, `live_verified:false`. Реальный `id` равен `item_id`, исходная ссылка сохранена в `url` и `original_url`.

| Sony WH-1000XM5, Black, New, модель 2022 | [377184719616](https://www.ebay.com/itm/377184719616) | $184 | US, Houston TX | $190 |
| Canon EOS R50, Black, New, корпус, модель 2023 | [334893883260](https://www.ebay.com/itm/334893883260) | $649.95 | US, Brooklyn NY | $660 |

Sony и Canon скопированы из исходных наборов с сохранением метаданных, включая оговорки об упаковке и гарантии. Canon остаётся кандидатом без медианы. Страны взяты из местоположения товара, не адреса доставки или страны производства.

Charizard дополнительно проверен по индивидуальной странице 15 ноября 2026. Кеш помечен «last week»; в нём явно указаны $360, Buy It Now, English, PSA 9, номер 199/165, SIR/Holo, 2023 и местоположение. Это новый исходный ID: координатор должен добавить запись в активный каталог, если он формируется только из первоначального файла. Старый $350 ID `900054604971` по индивидуальной странице не подтвердился; его нельзя использовать как подтверждённое отложенное объявление. Для сценария «пусто → совпадение» его также следует исключить из активного начального набора с сохранением истории происхождения.

Приложение сначала исключает `initial_feed_exclude_item_id` из исходной выдачи, сохраняет финальные условия пользователя, затем через 10 секунд подаёт соответствующую запись. Только совпадение вызывает уведомление. При приведённых бюджетах начальные остальные цены выше порога, а отложенное объявление подходит; приложение должно проверить это после интеграции каталога. Бюджет ниже $360/$184/$649.95, другая страна, другой товар или несовместимые характеристики не должны вызывать уведомление. Цены не подгоняются под произвольный бюджет.

Точная дата фиксации источников неизвестна, доступность сейчас не подтверждена. Доставка `null`, налоги и пошлины не включены. Год электроники — год модели, не дата изготовления экземпляра. Данные не подтверждают оплату подписки или фактическую отправку email/Telegram. Маркировать уведомление как демонстрационное появление сохранённого объявления, а не новый товар, найденный сейчас.

`excluded_source_ids:["900054604971"]` явно исключает старый $350 из runtime; исходная запись остаётся архивной. Координатор интеграции объединяет реальные staged-записи с каталогом по `item_id`, затем исключает staged-ID только из начального этапа появления. $360 подтверждён индивидуальной кэшированной страницей, не подменён вымышленной ценой.
