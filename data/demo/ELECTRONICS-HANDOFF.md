## Ограничения

Все данные взяты с кешированных страниц eBay, источники и выдержки сохранены в JSON. Текущая доступность не проверена, точный момент снимка неизвестен, доставка/налоги/пошлины не включены. Страна товара не означает доставку в неё и не доказывает региональную гарантию. Не изменять цены для эффектного результата. Не использовать старые синтетические Sony/Canon из products.mjs как реальные.

## Следующий шаг и владельцы

1. bagdaulet-dev читает ТЗ и согласует контракт text + overrides с aibarC; готовит UI и HTTP-слой в своей ветке.
2. aibarC адаптирует engine/parser для техники, года и стран под согласованный контракт. В этой передаче runtime НЕ изменён; нынешний AI endpoint по-прежнему карточный.
3. bagdaulet-dev подключает реальные файлы, убирает синтетические данные из основного сценария, проверяет локальную интеграцию по сценариям.
4. Деплой только в конце; Vercel и eBay API для этой задачи не требуются.

Проверено при подготовке:21 уникальный ID, URL содержит ID, положительные целые USD cents, live_verified false, неизвестная общая доставка null, подтверждённые страны имеют evidence.
